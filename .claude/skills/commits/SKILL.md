# Коммиты

Базовые правила — в `CLAUDE.md`, раздел «Коммиты». Перед фиксацией пройди
чек-лист.

## 1. Разбей работу

- Одна логическая правка — один коммит; фичу, рефакторинг и форматирование
  не смешивать.
- Каждый коммит должен собираться сам по себе. Перед фиксацией:
  `npx tsc --noEmit` и `npm run build`.
- Коммит создаётся только по просьбе пользователя. Если просьбы нет —
  предложи разбивку и подожди.

## 2. Сообщение

- Conventional Commits на английском: `type(scope): summary`
  (`feat(employees): ...`, `fix(chat): ...`, `refactor(sidebar): ...`).
- В теле — почему изменение сделано, а не пересказ диффа.
- **Не добавляй `Co-Authored-By: Claude ...` и любые другие подписи об
  авторстве** — ни в заголовок, ни в тело коммита.

## 3. Перед коммитом

- Посмотри `git status` и `git diff --cached`: не попадают ли `.env`, `dist/`,
  посторонние файлы.
- Стейджи конкретные файлы, а не `git add -A`.
- Пуш в `origin` — только по явной просьбе.
