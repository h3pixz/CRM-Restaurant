# Отчёт за день

Собери отчёт по фактам из git и `TASK.md`. Ничего не придумывай: если за день
изменений нет — так и напиши.

## 1. Собери данные

Выполни параллельно:

- `date +%F` — сегодняшняя дата для имени файла.
- `git log --since=midnight --date=short --pretty='%h %ad %s'` — коммиты за день.
- `git diff --stat` и `git diff --cached --stat` — незакоммиченные изменения.
- `git status --short` — новые и удалённые файлы.
- `git log --since=midnight -p -- TASK.md` — какие пункты чек-листа закрыты сегодня.

Если рабочее дерево чистое и коммитов нет — отчёт из одной строки об отсутствии
изменений, файл при этом всё равно создаётся.

## 2. Напиши файл

Путь: `docs/reports/YYYY-MM-DD.md`. Папку создай, если её нет.

Если файл за сегодня уже существует — **дополняй** его новыми пунктами, не
перезаписывай (за день может быть несколько сессий).

Шаблон:

```md
# 2026-10-30

## Итоги

Один-три абзаца: что сделано и в каком состоянии проект к концу дня.

## Сделано

- Что именно и зачем, сгруппировано по смыслу (экраны, данные, инфраструктура).

## Коммиты

- `abc1234` feat(employees): connect employees screen to firestore

## Изменённые файлы

- Кратко: какие области затронуты, объём по `git diff --stat`.


```

## 3. Отчитайся в чате

Покажи в ответе краткую версию (итоги + следующий шаг) и путь к файлу.
Сам отчёт в git не коммить — только если пользователь явно попросит.
