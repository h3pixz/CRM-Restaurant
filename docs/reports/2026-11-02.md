## Сделано

- Зафиксировано полное техническое задание проекта в `docs/TZ.md` и добавлена ссылка на него в `CLAUDE.md`.
- Модуль чата: клиент native WebSocket к `wss://ws.ifelse.io` с обработкой состояний подключения и переподключением, страница чата и её роут.
- Раздел Tables: Firestore-слой коллекций `tables` и `orders` с мапперами, валидирующими поля; экран схемы зала и экран заказа по столу, пункт в навигации и заголовок вложенного роута. Счётчики выводятся из данных Firestore, правки количества и выбора пока остаются локальными.
- Макеты схемы зала и заказа зафиксированы в репозитории как источник для проверки реализации.
- Из строк заказа убраны аватары блюд: без миниатюр колонка только смещала детали заказа.
- Админка: отдельный защищённый лейаут по макету с собственными sidebar и top bar (Tables / Orders / Statistics), вход по логину и паролю закрывает общий admin-лейаут.
- Restaurants переведены с захардкоженного массива на Firestore, мок-файл удалён.
- Исправлен цвет текста активной кнопки метрики во Filters: вариант `outline` давал тёмный текст на тёмном фоне при наведении.
- Правило отчёта за день изменено: файл пересоздаётся при каждом запуске вместо дополнения (`CLAUDE.md`, `.claude/skills/daily-report/SKILL.md`), старый отчёт удалён.
